# 기능 지식

CODE 205 기능별 설계와 구현 메모를 둔다. 기능 하나가 서버, DB, 프런트, 운영 설정을 함께 건드리면 전체 흐름을 먼저 요약하고 각 코드 위치로 연결한다.

## 문서

- [엔트리 실시간 변수/리스트 상태 모니터](entry-cloud-variable-status.md)

## 작성 규칙

- 기능 목적과 사용자에게 보이는 화면을 먼저 적는다.
- 서버/API/DB/프런트 파일을 각각 분리해서 적는다.
- 운영 중 켜지는 예약 작업, 외부 서버 호출, 기록 파일 위치를 함께 적는다.
- 구현 전 추정과 구현 후 확인된 사실을 구분한다.
- 비밀번호, 세션 쿠키, Entry 서버 토큰은 적지 않는다.
