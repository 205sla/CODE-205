# 기능 지식

CODE 205 기능별 설계와 구현 메모를 둔다. 기능 하나가 서버, DB, 프론트, 운영 설정을 함께 건드리면 이곳에 먼저 요약하고 각 코드 위치로 연결한다.

## 문서

- [실시간 리스트/변수 서버 상태 기능](entry-cloud-variable-status.md)

## 작성 규칙

- 기능 목적과 사용자에게 보이는 화면을 먼저 적는다.
- 서버/API/DB/프론트 파일을 각각 분리해서 적는다.
- 운영 중 켜지는 워커나 주기 작업은 테스트 환경에서 어떻게 비활성화되는지도 적는다.
- 구현 전 추정과 구현 후 확인된 사실을 구분한다.
