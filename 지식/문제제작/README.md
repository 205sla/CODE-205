# 문제제작 지식

문제 출제와 `.ent` 제작 과정에서 반복해서 쓰는 내부 지식을 둔다.

## 공개 가이드

- 루트의 `../PROBLEM_GUIDE.md`는 기여자에게 공개되는 출제 가이드다.
- `public/contribute.html`에서도 `PROBLEM_GUIDE.md`의 GitHub 경로를 직접 연결하므로 위치를 바꾸지 않는다.

## 내부 지식으로 둘 내용

- 문제 템플릿 개선 아이디어
- `.ent` 제작 자동화 팁
- 테스트 케이스 설계 패턴
- 자주 실패하는 채점 조건과 재현 방법
- 스프라이트/자산 운용 규칙 중 공개 가이드에 넣기 애매한 세부사항
