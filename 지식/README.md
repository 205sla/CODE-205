# CODE 205 지식

이 폴더는 `code.205.kr` / `apps/MYentry` 프로젝트에만 해당하는 구현, 운영, 검증 지식을 보관한다.

공개 안내 문서나 외부에서 직접 링크하는 문서는 루트에 둔다. 예를 들어 `../README.md`, `../PROBLEM_GUIDE.md`, `../NOTICE.md`는 현재 위치를 유지한다.

## 분류

| 위치 | 용도 |
|---|---|
| `entry-reference/` | CODE 205에서 쓰는 EntryJS API, 파일 포맷, 엔진, vendoring 참고문서 |
| `기능/` | 기능별 설계, 구현 포인트, 서버/API/프론트 연결 방식 |
| `운영/` | 배포, PM2, SQLite, 서버 설정, 장애 대응, 모니터링 |
| `문제제작/` | 문제 출제, `.ent` 제작, 테스트 케이스, 스프라이트 운용 지식 |

## 현재 핵심 문서

- [EntryJS 참고문서](entry-reference/README.md)
- [실시간 리스트/변수 서버 상태 기능](기능/entry-cloud-variable-status.md)
- [운영 지식](운영/README.md)
- [문제제작 지식](문제제작/README.md)

## 배치 규칙

- CODE 205의 파일 경로, API, DB 스키마, PM2 설정, 화면 동작처럼 프로젝트 전용인 내용은 이 폴더에 둔다.
- ENTRY 전체에 공통인 작업 규칙, 검증 정책, 로컬 Entry 서버 사용법은 `../../../_docs`에 둔다.
- 기여자나 사용자에게 공개되어야 하는 안내는 루트 문서나 `public/` 페이지에 둔다.
- `.agents/`와 `.claude/`의 스킬 파일은 도구 실행용 자산으로 유지하고, 사람이 읽는 요약은 필요하면 이 폴더에 따로 적는다.
