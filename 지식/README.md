# CODE 205 지식

이 폴더는 `code.205.kr` / `apps/MYentry` 프로젝트에만 해당하는 구현, 운영,
검증 지식을 보관한다.

## 분류

| 위치 | 용도 |
|---|---|
| `기능/` | 기능별 설계, 구현 메모, 서버/API/프런트 연결 방식 |
| `운영/` | 배포, PM2, SQLite, Nginx와 서버 설정 |

## 문서

- [Entry Online](기능/entry-online.md)
- [운영 지식](운영/README.md)

## 배치 규칙

- CODE 205의 파일 경로, API, DB, PM2 설정처럼 프로젝트 전용 내용은 여기에 둔다.
- ENTRY 전체에 공통인 런타임 접근법과 작업 규칙은 `../../../_docs`에 둔다.
- 확장 프로그램 구현 지식은 확장 저장소의 `지식/`에 둔다.
- 비밀번호, 세션 쿠키, 배포 키 같은 민감값은 기록하지 않는다.
