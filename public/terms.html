이용약관

본 약관은 code.205.kr에서 제공하는 엔트리 블록 코딩 기반 학습 도구의 이용 조건을 정합니다.

핵심 요약
  1. 계정 없이 무료로 사용하는 학습 도구입니다.
  2. 클리어 기록은 현재 브라우저에만 저장됩니다.
  3. 서비스와 로컬 데이터의 지속성은 보장되지 않습니다.
  4. Entry Labs의 공식 서비스가 아닙니다.

제1조 (서비스의 범위)

서비스는 문제 목록, 엔트리 기반 편집기, 브라우저 자동 채점, 작품 파일 내보내기 및 작품 합치기 도구를 제공합니다. 회원가입, 로그인, 서버 코드 보관 및 기기 간 동기화 기능은 제공하지 않습니다.

제2조 (로컬 데이터)

  • 정답을 통과한 문제 ID와 문제 목록 필터는 브라우저의 localStorage에 저장됩니다.
  • 브라우저 데이터 삭제, 시크릿 모드 종료, 기기·브라우저 변경 등으로 기록이 사라질 수 있습니다.
  • 운영자는 이용자의 브라우저에 저장된 데이터를 열람하거나 복구할 수 없습니다.

제3조 (이용자의 의무)

  • 서비스의 정상 운영을 방해하거나 다른 이용자에게 피해를 주는 행위를 해서는 안 됩니다.
  • 문제, 소스 코드, 이미지 및 기타 자료를 이용할 때 각 자료의 라이선스와 저작권을 준수해야 합니다.
  • 오류나 보안 문제를 발견한 경우 공개 악용 전에 운영자에게 알려주시기 바랍니다.

제4조 (비공식 서비스 및 상표)

CODE 205는 엔트리의 공식 서비스가 아닙니다. EntryJS와 관련 오픈소스는 각 라이선스에 따라 사용됩니다. 자세한 출처와 라이선스는 저장소의 NOTICE.md를 확인해 주세요.

제5조 (서비스 변경·중단)

운영자는 문제, 채점 방식, 기능, 배포 환경을 변경하거나 서비스를 일시 또는 영구 중단할 수 있습니다. 가능한 경우 저장소나 사이트를 통해 주요 변경을 안내합니다.

제6조 (보증 및 책임 제한)

  • 서비스는 현재 상태 그대로 제공되며 정확성, 무중단 제공 또는 특정 목적 적합성을 보증하지 않습니다.
  • 채점 오류, 브라우저 호환 문제, localStorage 삭제, 파일 손상 또는 서비스 중단으로 발생한 손해에 대해 운영자는 법령이 허용하는 범위에서 책임을 지지 않습니다.
  • 중요한 작품은 “내 컴퓨터에 저장하기” 기능으로 별도 보관하는 것을 권장합니다.

제7조 (약관 변경)

약관은 서비스 구조나 관련 정책 변경에 따라 수정될 수 있으며, 최신 내용은 항상 이 페이지에 게시됩니다.
