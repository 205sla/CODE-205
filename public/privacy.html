개인정보 처리방침

CODE 205는 계정 없이 사용하는 정적 학습 사이트입니다. 서비스 애플리케이션은 이용자를 식별하기 위한 개인정보를 수집하거나 별도 서버로 전송하지 않습니다.

요약
  1. 회원가입·로그인·서버 동기화 기능을 제공하지 않습니다.
  2. 문제 클리어 기록과 필터 설정은 현재 브라우저에만 저장됩니다.
  3. 작성한 프로젝트와 합치기 대상 파일은 브라우저 안에서 처리됩니다.
  4. 다른 기기와 동기화되지 않으며 브라우저 데이터 삭제 시 복구할 수 없습니다.

기존 회원 기능 종료와 데이터 삭제

CODE 205는 서버 유지비 부담을 줄이면서 문제 풀이 서비스를 계속 제공하기 위해 기존 회원가입·로그인·서버 저장 기능을 종료하고 GitHub Pages 기반의 정적 서비스로 전환했습니다.

전환 전에 CODE 205 서버가 보관하던 회원정보, 비밀번호 해시, 출생연도, 선택 입력한 이메일·표시 이름, 로그인 세션, 서버 클리어 기록과 제출 코드는 모두 삭제했습니다. 별도 백업이나 사본을 남기지 않았으며, 기존 개인정보는 더 이상 보관하거나 이용하지 않습니다.

문제 풀이, 브라우저 채점, .ent 저장과 작품 합치기는 계정 없이 계속 이용할 수 있습니다.

1. 브라우저에 저장되는 정보

저장 항목용도
localStorage.entry:solved정답을 통과한 문제 ID 목록
localStorage.entry:filter문제 목록의 난이도·해결 여부 필터

이 값은 https://code.205.kr origin의 브라우저 저장소에만 존재합니다. CODE 205 애플리케이션은 해당 값을 서버로 업로드하지 않습니다.

2. 작품 데이터 처리

  • 문제 풀이와 자동 채점은 브라우저에서 실행됩니다.
  • “내 컴퓨터에 저장하기”는 프로젝트와 자산을 브라우저에서 .ent 파일로 묶어 내려받습니다.
  • 작품 합치기는 선택한 파일을 브라우저 안에서 처리하며 파일을 CODE 205 서버로 업로드하지 않습니다.

3. 쿠키와 분석 도구

CODE 205 애플리케이션은 로그인 쿠키, 광고 쿠키 또는 Google Analytics 같은 제3자 분석 도구를 사용하지 않습니다.

4. 정적 호스팅 사업자의 처리

사이트 파일은 GitHub Pages를 통해 제공될 수 있습니다. 이 과정에서 GitHub가 서비스 보안과 제공을 위해 IP 주소, User-Agent, 요청 시각 같은 접속 정보를 처리할 수 있으며, 해당 처리는 GitHub의 정책을 따릅니다. 자세한 내용은 GitHub 개인정보 보호정책을 확인해 주세요.

5. 저장 정보 삭제

브라우저 설정에서 code.205.kr의 사이트 데이터를 삭제하면 로컬 클리어 기록과 필터 설정이 삭제됩니다. 삭제된 데이터는 운영자가 복구할 수 없습니다.

6. 이용자의 주의사항

  • 다른 브라우저·프로필·기기에는 기록이 자동으로 복사되지 않습니다.
  • 시크릿 모드나 브라우저의 자동 저장소 정리 정책에서는 기록이 사라질 수 있습니다.
  • 공용 기기에서는 이용 후 사이트 데이터를 직접 삭제해 주세요.
